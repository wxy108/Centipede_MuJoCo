# Conditional completion of a budget-limited joint polish

Declared before the initial twelve-poll joint polish finishes and before any
nonzero contact-erasure result. No PD, plant, domain, metric, or engineering gate
changes. The existing twelve-poll record and its budget-limit flags remain intact.

If all starts meet the existing gain criterion, this continuation exits without
interrupting qualification or running any candidate. If any start reaches the
poll budget while still improving by more than0.2mm, it alone remains unresolved
for local search. Apply the same rule to every such wave. Wave number, amplitude
ordering, and future contact behavior do not enter the rule.

At the completed joint-polish boundary, verify and stop only the original owned
driver, before qualification starts. Continue the unresolved starts for at most
twelve additional polls. Each poll retains the existing fourteen directions at
normalized step0.005. It also tests normalized distances0.01,0.02,0.04 along the
last successful displacement direction (scaled to unit infinity norm). These
three pattern probes accelerate progress along a repeatedly successful direction;
they do not prescribe any particular amplitude or wave trend. Clip only to the
same three amplitude bounds, cache identical candidates, and assess every new
candidate with the unchanged nominal simulator and gates.

Keep the highest-displacement feasible candidate. Stop a start when gain is no
greater than0.2mm. Preserve and report any second budget exhaustion; this remains
a finite search, with no global or arbitrary-direction convergence claim. After
this bounded completion, call the unchanged6s/12s/half-timestep qualification.
Contact work still waits for completed qualification and frozen amplitudes.

Receipts must distinguish the original twelve-poll audit, the conditional
decision, any driver handover, and the additional result. No existing frozen
search or contact-analysis source is edited.
